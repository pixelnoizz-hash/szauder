How to get a Client ID (once, about 10 minutes)
  1. Open console.cloud.google.com, create a project, e.g. Ray Studio.
  2. APIs & Services → Library: enable Google Drive API.
  3. Google Auth Platform (OAuth consent screen): app name, your e-mail, audience External. Leave it in Testing and add your own Google address under Test users. Nobody else can then sign in.
  4. Clients → Create client → Web application. Under Authorized JavaScript origins add the address Ray Studio runs on, e.g. https://davidarielszauder.com (for a local test: http://localhost:8080). No redirect URI is needed.
  5. Copy the Client ID (ends in .apps.googleusercontent.com) here and press Save & connect.

Google sign-in does not work on a page opened as a file (file://). Put the page on your site, or in its folder run python3 -m http.server 8080 and open http://localhost:8080/ray-studio.html. Keys and the local gallery belong to the address, so you enter the keys once more there.
